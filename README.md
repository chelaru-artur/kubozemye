# Кубоземье

Воксельная игра-песочница на Three.js для браузера и телефона: добывай землю, дерево и камень,
строй дом и переживи ночь с зомби. Мир бесконечный, постройки сохраняются в браузере.

```sh
npm install
npm run dev      # открыть на компьютере и с телефона в той же сети (адрес покажет Vite)
npm test         # проверки мира, физики и рюкзака
npm run build    # один самодостаточный файл dist/index.html
```

Графика и звук генерируются кодом, сторонних игровых ресурсов в проекте нет.
